# Shollu Modern 1.0

Status per 30 September 2026: versi 1.0.0 berada di `main` dan sudah dikonfirmasi berfungsi oleh pengguna pada Windows. Installer lokal sudah dibangun dengan audio Shollu3; signing dan distribusi publik ditunda. Belum ada installer v1 di GitHub Releases.

Antarmuka mengikuti `design_handoff_shollu_ui`: Tenang memakai rail ikon dan day arc; Ringkas memakai tab, tabel bulanan, inspector, dan status bar. Pilihan mode, bahasa Indonesia/English, tiga tema, dan lima aksen disimpan bersama pengaturan aplikasi.

## Fitur

Ada tujuh halaman: Utama, Jadwal, Pengingat, Konversi, Lokasi, Pengaturan, dan Tentang. Menutup jendela utama menyembunyikannya ke tray agar pengingat tetap berjalan; pilih Exit dari tray untuk keluar sepenuhnya.

- Jadwal sholat memakai koordinat, ketinggian, zona waktu tetap, lima metode, pilihan Asar, pembulatan, dan koreksi menit. Jam dan pergantian hari mengikuti zona lokasi yang dipilih.
- Pencarian kota menggunakan basis data offline dari berkas `.spn` asli. Periksa zona waktu setelah memilih kota; basis data asli tidak menyimpan zona waktu atau aturan daylight saving.
- Halaman Lokasi memisahkan pratinjau dari pengaturan tersimpan. Simpan atau urungkan perubahan sebelum meninggalkan pekerjaan yang belum selesai.
- Kalender bulanan, detail hari, ekspor CSV/HTML/TXT dengan dialog penyimpanan native, serta konversi Masehi–Hijriah dengan koreksi −1/0/+1 hari.
- Pengingat kustom dapat dibuat, diedit, diaktifkan, dinonaktifkan, dan dihapus. Waktu pengingat kustom mengikuti waktu lokal komputer; pengingat sholat mengikuti zona lokasi.
- Notifikasi tetap berjalan ketika jendela utama disembunyikan ke tray. Audio bawaan Shollu3 memakai `azan-fajr.mp3` untuk Subuh, `azan-mecca.mp3` untuk Dzuhur/Isya, `azan-egypt.mp3` untuk Ashar, dan `azan-dammam.mp3` untuk Magrib; `dua.mp3` menyusul setelah adzan. Berkas pilihan pengguna dapat mengganti suara adzan untuk semua waktu sholat. Syuruq tidak memicu adzan. Basmallah/hamdallah disertakan untuk pekerjaan berikutnya, tanpa pemicu saat ini ([#45](https://github.com/adenaufal/shollu-modern/issues/45)).
- Bilah melayang dan drop zone berbagi jadwal serta pengaturan, berubah ukuran mengikuti mode, dan menyimpan keadaan saat ditutup.
- Pengaturan selalu di atas dan mulai saat masuk diterapkan ke sistem operasi. Aksi pengingat seperti perintah, shutdown, dan hibernasi menjalankan aksi yang dipilih pengguna.

## Pintasan

| Pintasan | Fungsi |

## Pengembangan dan verifikasi

Gunakan Node.js 22.x ≥22.13.0, pnpm 11, Rust stable, serta dependensi native yang dijelaskan di [CONTRIBUTING.md](../CONTRIBUTING.md). CI memakai Node 22.13.0. `pnpm tauri dev` menjalankan frontend dan runtime desktop; `pnpm dev` sendiri hanya frontend.

```powershell
pnpm install --frozen-lockfile
pnpm test
pnpm build
cargo fmt --manifest-path src-tauri/Cargo.toml --check
cargo test --locked --manifest-path src-tauri/Cargo.toml --lib
cargo clippy --locked --manifest-path src-tauri/Cargo.toml --lib -- -D warnings
```

Uji native Windows memerlukan WebView2 dan aplikasi debug yang sudah dikompilasi. Jalankan `pnpm dev` pada terminal terpisah, kemudian `cargo build` di `src-tauri` dan `pnpm test:desktop` dari root. Skrip memakai folder `.smoke/native-data-*` untuk menghindari perubahan data pengguna dan menghasilkan laporan serta screenshot di `.smoke`. `SHOLLU_SMOKE_BINARY` dapat menunjuk executable release untuk menguji aset terkemas.

`SHOLLU_CONFIG_DIR` mengalihkan pengaturan, pengingat, dan basis data ke direktori terpisah. Mode ini menolak aktivasi autostart agar konfigurasi uji tidak didaftarkan ke startup komputer.

Untuk menguji executable release dari PowerShell setelah build, tanpa Vite:

```powershell
$env:SHOLLU_SMOKE_BINARY = (Resolve-Path 'src-tauri/target/release/shollu-modern.exe').Path
pnpm test:desktop
Remove-Item Env:SHOLLU_SMOKE_BINARY
```

Uji mencakup pemutaran lima rekaman adzan, penyelesaian doa setelah adzan kustom pendek, stop, pemulihan suara bawaan, serta penolakan Syuruq sebagai adzan. Audio pengujian dimute dan file uji berada di konfigurasi terisolasi.

## Paket aplikasi

```powershell
pnpm tauri build --bundles nsis --config '{"bundle":{"createUpdaterArtifacts":false}}'
```

Perintah lokal di atas membuat installer Windows tanpa artefak updater bertanda tangan. Pipeline release memakai secret signing updater yang tersedia di GitHub dan membuat draft release saat tag versi dikirim. Signing updater berbeda dari Windows Authenticode dan notarization macOS; jangan menganggap installer sudah memiliki keduanya.

Installer berada di `src-tauri/target/release/bundle/nsis/Shollu Modern_1.0.0_x64-setup.exe`. Build lokal terakhir berukuran sekitar 8,10 MiB. Installer ini untuk percobaan pribadi dan belum ditandatangani Authenticode. Dependensi/build pertama memerlukan internet; jadwal, kota, font, dan rekaman bawaan tersedia offline setelah aplikasi terpasang.

Untuk sertifikat dan build Authenticode lokal, ikuti [panduan signing Windows](release/windows-local-signing.md).

CI memeriksa build frontend, tes frontend, format Rust, tes Rust, dan Clippy pada Windows, macOS, dan Linux. Uji interaksi desktop dilakukan pada Windows; hasil CI platform lain tidak menggantikan uji antarmuka native pada platform tersebut.

Verifikasi lokal v1.0: 38 tes Rust, pemeriksaan resolver audio khusus build release, 6 tes frontend, pemeriksaan TypeScript/build, Clippy tanpa warning, dan 17 kelompok uji native untuk ketujuh halaman di kedua mode, perubahan pengaturan, pengingat, overlay, dialog ekspor, serta audio. Ketujuh MP3 terkemas cocok dengan hash file Shollu3 sumber; installer menyertakan notice lisensi asli. Aksi shutdown/hibernasi tidak dijalankan dalam smoke test agar pengujian tidak mematikan komputer.
