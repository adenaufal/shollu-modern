# Original Shollu3 audio

These seven MP3 recordings were copied unchanged from the user's installed Shollu3 distribution. Source: `E:\Program Files (x86)\Shollu3`. Original application: Shollu by **Ebta Setiawan**. This local source path is provenance only; runtime uses packaged resources.

| Prayer | Default recording |
| --- | --- |
| Fajr / Subuh | `azan-fajr.mp3` |
| Dhuhr / Dzuhur | `azan-mecca.mp3` |
| Asr / Ashar | `azan-egypt.mp3` |
| Maghrib / Magrib | `azan-dammam.mp3` |
| Isha / Isya | `azan-mecca.mp3` |

`dua.mp3` follows each adhan in the same playback queue. A selected custom audio file overrides the adhan recording for all prayers and still precedes the bundled dua. Stop cancels the whole queue. Sunrise never plays adhan.

`basmallah.mp3` and `hamdallah.mp3` are packaged for future work and have no runtime triggers yet. Follow-up: [issue #45](https://github.com/adenaufal/shollu-modern/issues/45).
